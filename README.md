# Planetarium Razan

Simulasi tata surya interaktif berbasis web dengan visualisasi 3D, animasi sinematik, dan narasi suara.

## Fitur

- **9 Benda Langit** — Matahari, Merkurius, Venus, Bumi (+ Bulan), Mars, Jupiter, Saturnus, Uranus, Neptunus
- **Tekstur Detail** — Setiap planet memiliki tekstur unik (kawah, atmosfer, band, cincin, kutub es, dll)
- **Demo Tour Sinematik** — Tur otomatis ke setiap planet dengan animasi zoom in/out mewah dan efek warp speed
- **Narasi Suara** — Suara narator bahasa Indonesia yang menjelaskan setiap planet saat tour
- **Backsound Orchestral** — Musik latar megah yang bisa diputar kapan saja
- **Follow Mode** — Klik planet untuk mengikuti pergerakannya secara real-time
- **Info Detail** — Panel informasi lengkap untuk setiap planet (fisik, atmosfer, orbit, fun fact)
- **28 Rasi Bintang** — Orion, Ursa Major, Ursa Minor, Cassiopeia, Cygnus, Scorpius, Crux, Leo, dan banyak lagi
- **10.000 Bintang** latar belakang
- **Kontrol Waktu** — Percepat, perlambat, atau pause simulasi
- **Layer Toggle** — Tampilkan/sembunyikan bintang, konstelasi, orbit, label, grid

## Cara Menggunakan

1. Buka `index.html` di browser modern (Chrome, Firefox, Edge)
2. **Navigasi**: Drag mouse untuk rotasi, scroll untuk zoom
3. **Klik planet** untuk melihat info detail dan mengikuti planet tersebut
4. **Demo Tour**: Klik tombol "Demo Tour" untuk tur sinematik otomatis
5. **Musik**: Klik tombol "Musik" untuk mengaktifkan backsound orchestral
6. **Kontrol waktu**: Gunakan tombol rewind/forward untuk mengatur kecepatan simulasi

## Persyaratan

- Browser modern (Chrome, Firefox, Edge)
- Koneksi internet
- Speaker/headphone untuk pengalaman audio terbaik
